# Posty (ShareArticle)

Web で読んだ記事をストックして、日報や友人へのシェアに活用できる iOS アプリ。

## 機能

- ブラウザの Share Extension から記事を保存
- OGP 情報を自動取得してサムネイル付きで一覧表示
- 日付別に記事を整理
- アプリ内ブラウザで記事を閲覧
- ブックマーク管理

## 技術スタック

- Swift / UIKit / iOS 10+
- Firebase (Auth / Realtime Database)
- OpenGraph / AlamofireImage
- Share Extension + App Groups
